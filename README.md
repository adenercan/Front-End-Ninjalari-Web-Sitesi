# Front-End Ninjalari Web Site

A **responsive multi-page portfolio website** built as a **team project** to apply core Front-End development skills including HTML, CSS, and JavaScript.

This project was completed with a three-person team to practice real-world workflows such as responsive design, DOM interaction, and UI state management.

## 🚀 Key Features

- **Responsive Design** — Works smoothly on mobile, tablet, and desktop  
- **Interactive Elements** — JavaScript-driven UI interactions  
- **Theme Management** — Light & dark mode with preference saved using `localStorage`  
- **Multi-Page Structure** — Landing, about, projects, and individual profile pages  
- **Clean Code Structure** — Semantic HTML and well-organized CSS

## 🛠️ Technologies Used

- **HTML5** — Page structure  
- **CSS3** — Layout, responsiveness, and design  
- **JavaScript (ES6+)** — DOM manipulation and theme logic  
- **localStorage** — Persisting theme preference

## 🎯 What I Focused On

- Building a **real responsive website** that adapts across devices  
- Collaborating in a **team development workflow**  
- Managing UI state (like theme) using **localStorage**  
- Writing readable and maintainable front-end code  
- Structuring navigation for multiple pages

## 🧠 How It Works

1. Users navigate between multiple pages (Home, About, Projects, Profiles)  
2. Theme selection (light/dark) is updated dynamically  
3. Chosen theme is stored to persist between sessions  
4. JavaScript enhances interactivity and usability
